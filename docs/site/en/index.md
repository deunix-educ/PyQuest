# PyQuest

**Learn Python by doing, right in your browser.** No installation, no account: open the page, write code, see
the result. The app also works offline.

## What you get

- **Real Python.** Your code is run by CPython (through Pyodide) inside your browser. Errors are Python's real
  errors, explained in plain language.
- **15 levels** (from "What is a program?" to classes and a small drawing project), each with short explanations,
  guided exercises, progressive hints and a final mission.
- **Visible progress**: experience points (XP), badges, a day streak, a map of the path.
- **Accessible**: full keyboard use, light and dark themes, adjustable text size, sound and voice always
  switchable off, interface in French and English.

## Project principles

- **Self-contained**: everything happens in the browser. A server is only needed to host the files, and syncing
  between devices is **optional**.
- **Privacy**: no analytics, no third-party service. Nothing leaves your device unless you turn on sync.
- **Open**: MIT licence, levels written in YAML, a built-in level editor to contribute without coding.

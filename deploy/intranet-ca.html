PyQuest — certificat du réseau

Ce serveur utilise le certificat de l'établissement, que votre navigateur ne connaît pas encore. À faire une seule fois par poste (ou une fois pour tous par l'administrateur du réseau) :

Télécharger le certificat (pyquest-ca.crt)

Windows (Chrome, Edge)

Ouvrir le fichier, Installer le certificat, Ordinateur local, Placer tous les certificats dans le magasin suivant : Autorités de certification racines de confiance. Redémarrer le navigateur.

Firefox

Paramètres › Vie privée et sécurité › Afficher les certificats › Autorités › Importer, cocher « Confirmer cette AC pour identifier des sites web ».

Linux

Debian/Ubuntu : copier le fichier dans /usr/local/share/ca-certificates/pyquest-ca.crt puis sudo update-ca-certificates. Chromium : certutil -d sql:$HOME/.pki/nssdb -A -t "C,," -n PyQuest -i pyquest-ca.crt.

Android, iPhone, iPad

Ouvrir le fichier et l'installer dans les réglages (Android : Sécurité › Installer un certificat CA ; iOS : installer le profil, puis Réglages › Général › Informations › Réglages des certificats : activer la confiance totale).

Administrateur du réseau

Le déploiement groupé (stratégie de groupe Windows, gestion des postes) évite toute manipulation : importer pyquest-ca.crt dans les autorités racines de confiance des postes.

PyQuest — network certificate

This server uses your school's certificate, which browsers do not know yet. Do this once per computer (or once for all by the network administrator): download pyquest-ca.crt and add it to the trusted root certificate authorities — Windows: open the file › Install certificate › Local machine › Trusted Root Certification Authorities; Firefox: Settings › Privacy & Security › View certificates › Authorities › Import; Linux: /usr/local/share/ca-certificates/ then sudo update-ca-certificates; Android/iOS: open the file and install it in the settings. Then restart the browser and open the PyQuest address.

# Stratégie anti-abandon

| Mécanisme | Justification |
|---|---|
| **Micro-victoires à chaque étape** (pas seulement en fin de niveau) | Le renforcement positif doit arriver en quelques secondes, pas en fin de session — sinon l'apprenant décroche avant d'atteindre la récompense. |
| **Indices gradués, jamais la solution d'un coup** | Donner la solution trop tôt casse le sentiment de compétence (variable clé de la motivation intrinsèque) ; ne jamais aider détruit la confiance. Les deux extrêmes font décrocher, d'où la gradation. |
| **Traduction systématique des erreurs + ton rassurant** (« une erreur, c'est un indice ! ») | La peur du message d'erreur rouge est le point de décrochage n°1 chez le grand débutant (association erreur = échec personnel). Reformuler désamorce cette association. |
| **Le code de l'apprenant n'est jamais perdu après une erreur** (pas de reset de cellule) | Perdre son travail après une erreur est une friction classique de décrochage ; l'apprenant doit pouvoir corriger localement. |
| **Carte de progression visible** (niveaux complétés / restants) | Effet de « goal gradient » : la motivation augmente quand la distance à l'objectif devient visible et se réduit. |
| **Une seule notion nouvelle par écran** | Respecte la charge cognitive limitée du débutant ; mélanger deux notions nouvelles double le risque de blocage simultané. |
| **Durée de niveau bornée (≤ 30–40 min)** | Un niveau trop long épuise avant la mission finale, qui est le moment le plus motivant — il doit arriver avant la fatigue. |
| **Missions concrètes et « montrables »** (mot de passe généré, dessin, agenda) plutôt qu'exercices abstraits | Le sens utilitaire perçu de la tâche est un facteur de persévérance documenté ; un exercice abstrait n'a pas cette valeur. |
| **Streak quotidien sans pénalité punitive à la rupture** | Construit une habitude sans culpabiliser en cas d'oubli — un streak qui se « brise » violemment pousse à l'abandon plutôt qu'à la reprise. |
| **Personnage-guide aux messages variés** (pas de phrase répétée à l'identique) | Le feedback perçu comme robotique/répétitif perd son effet motivant après quelques occurrences. |
| **Pas de classement compétitif global** | La comparaison aux autres décourage les débutants plus lents ; on compare l'apprenant à sa propre progression, jamais à celle d'un tiers. |
| **Reprise possible d'un niveau déjà réussi, sans pénalité** | Respecte l'autonomie de l'apprenant (réviser n'est pas un échec) plutôt que de l'enfermer dans une progression strictement linéaire. |
| **Son et voix toujours désactivables, jamais seule source d'info critique** | Contrainte d'accessibilité, mais aussi anti-abandon : un environnement bruyant imposé (ex. en classe, en open space) ferait fuir l'apprenant plutôt que de l'adapter. |
